This project walks you through using OpenCV to track hand movements. These movements are passed to an Arduino to control a servo motor. Additionally the project highlights using OpenCV and the contour method to highlight
its weakness in comparison to mediapipe. If using a MAC please select the MAC file for the python program. Arduino code remains the same for all. 

Note: The python program will only run with python 3.12.1 or lower.
      Install OpenCV, numpy, and serial as well.
